============================================================
12. AI REPLY GENERATION
============================================================

When a message arrives:

1. Identify the contact or group.
2. Check whether it is selected.
3. Check automation settings.
4. Load that contact's or group's system prompt.
5. Load relevant writing samples.
6. Load recent conversation history.
7. Load relevant approved memory.
8. Check which providers are permitted to receive this content.
9. Select an enabled available AI provider.
10. Generate a concise response.
11. Validate the response.
12. Check for duplicates and unsafe commitments.
13. Save the draft.
14. Request approval unless the user explicitly enabled automatic mode for that conversation.

Never invent personal commitments, appointments, payments or facts.

Never disclose private information.

Never automatically respond to OTPs, financial transactions, sensitive requests or high-risk messages.

Keep group replies disabled by default.
